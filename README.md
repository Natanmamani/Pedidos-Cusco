# Pedidos Cusco

Sistema web para la gestión de pedidos de comida local, desarrollado para
una startup de Cusco. Este repositorio contiene la base del proyecto y se
gestiona con Git y GitHub desde el inicio.

## Descripción

La aplicación permitirá a los clientes consultar la carta de los
restaurantes locales, registrar pedidos y hacer seguimiento de su estado;
y a los negocios, administrar productos y pedidos recibidos.

## Funcionalidades previstas

- Registro e inicio de sesión de usuarios.
- Catálogo de restaurantes y platos.
- Carrito y registro de pedidos.
- Seguimiento del estado del pedido.
- Panel de administración para restaurantes.

## Tecnologías

- Control de versiones: Git
- Repositorio remoto: GitHub
- Editor: Visual Studio Code

## Instalación

```bash
git clone https://github.com/Natanmamani/Pedidos-Cusco.git
cd pedidos-cusco
```
